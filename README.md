# WindowsLoopSend 定时指令自动发送工具

一款专为 Windows 平台打造的轻量级无侵入式自动化交互工具。无需安装任何扩展或插件，通过底层 API 强行抢占窗口焦点，结合剪贴板注入与键盘/鼠标事件模拟，实现定时向指定窗口（OpenCode、VS Code、Windows Terminal、CMD、浏览器等）自动粘贴提示词并回车发送。

---

## 核心特性

* **准星拖拽瞄准（Spy++ 风格）**：按住准星图标拖曳至目标输入框松开，自动获取目标窗口句柄并记录全局屏幕物理坐标。
* **突破抢焦点拦截**：内置 `AttachThreadInput` 与键盘状态模拟，穿透 Windows 防后台偷焦点限制，强制唤醒并置顶目标窗口。
* **高分屏 DPI 自适应**：原生调用 `SetProcessDpiAwareness`，避免 2K/4K 屏或 Windows 缩放比例（125%、150% 等）导致鼠标点击坐标错位。
* **剪贴板原子输入**：采用系统剪贴板配合 `Ctrl+V` 模拟粘贴，彻底解决逐字模拟按键带来的长文本丢字、特殊标点乱码及中文输入法拦截问题。
* **多提示词轮转发送**：以多条独立输入框形式提前填入 n 条内容（每条可多行），支持两种策略——**顺序循环**（按顺序发完再从头循环）与**随机发送**（每次随机取一条，不漏发）。
* **[附加前言]**：可选前言文本，合并到每次发送内容的开头。
* **[追加后续]**：可选后续文本，在主内容触发后延时若干秒再发送（循环模式下延时上限不超发送间隔，避免冲突）。
* **单次 / 循环调度**：
* **单次模式**：指定日期与精确时间执行，任务完成后自动终止。
* **循环模式**：设置执行间隔（分钟），支持启动时是否立即执行首发，可配置开始与截止日期（过期自动忽略）。
* **实时时间与触发预览**：界面实时显示当前时间，并自动/手动【刷新】按当前时刻重算“未来定时发送”清单。
* **多实例隔离**：点击 **“🆕 新建窗口”** 为另一个目标窗口开一个完全独立的实例（独立进程 + 独立配置文件），各实例的目标、提示词、前言/后续、定时、配置互不影响。
* **配置管理**：UI 修改自动保存（400ms 防抖）+ 配置文件外部修改热更新；支持 **手动保存 / 导入配置 / 恢复出厂**；配置文件位于 exe 同级目录（`config-<实例名>-win-auto-sender.ini`）。
* **日期版本化**：versionCode = 构建日期（`YYYYMMDD`），发布用纯数字 tag，检查更新对接 GitHub（主源）/ Gitee（备源）。

* **操作系统**：Windows 10 / Windows 11 (x64)

## 快速上手

### 1. 克隆仓库并安装依赖

```bash
git clone https://github.com/yezijinn/win-auto-sender.git
cd win-auto-sender
pip install PySide6 pywin32 pyperclip
```

### 2. 运行程序

> **重要提示（UAC 权限隔离说明）**：
> 若目标窗口是以**管理员身份**运行的进程（如管理员权限的 Windows Terminal、VS Code 或 CMD），本工具**必须同样以管理员身份运行**，否则 Windows 的 UIPI（用户界面特权隔离）机制会静默拦截所有按键与鼠标消息。

```bash
python win-auto-sender.py
```

亦可直接双击 `dist\WindowsLoopSend.exe`。

## 使用步骤

1. **绑定窗口与定位编辑框**：
* **方法 A（推荐）**：鼠标左键按住界面右上方的 **准星方框** 不放，光标变为十字，拖拽到目标软件的文字输入区后松开。程序自动绑定该窗口并回填坐标。
* **方法 B**：在下拉列表中直接选择已打开的可见窗口，手动调整或清空坐标。
2. **输入提示词**：在“发送内容”卡片中填写多条内容（**每个输入框即一条完整发送内容，可多行**），用右侧 **✕** 删除、底部 **➕** 新增；可选填 **[附加前言]** 与 **[追加后续]**；选择“**顺序循环发送**”或“**随机发送**”策略。
3. **设置触发策略**：
* **单次任务**：设置具体触发时间。
* **循环任务**：勾选循环任务，设定循环间隔（分钟），并选择是否立即执行第 1 次；可配置开始与截止日期。
4. **测试与挂机**：
* 建议先点击 **“⚡ 立即测试触发 1 次”**，确认窗口能正常弹到前台并回车发送。
* 测试通过后，点击 **“▶ 启动定时监听”** 即可挂机运行。

## 多窗口 / 多目标

点击 **“🆕 新建窗口（用于新的目标）”** 即可新开一个完全独立的程序窗口来管理另一个目标窗口——每个实例是独立进程、独立配置文件（`config-<name>-win-auto-sender.ini`），其发送内容、前言/后续、定时、目标窗口全部独立互不影响。启动时也可用 `--name <实例名>` 选择专属配置文件。

## 配置管理

* 配置文件：`config-win-auto-sender.ini`（与脚本/exe 同级目录）。
* 任意 UI 修改自动保存（400ms 防抖）；外部修改配置文件会热同步回 UI。
* 顶栏按钮：**💾 保存配置**、**📥 导入配置**（选 `.ini` 文件应用）、**♻️ 恢复出厂**（需确认，任务运行中阻止）。

## 常见问题与排查 (FAQ)

* **Q: 为什么日志显示“已发送”，但目标窗口完全没有输入内容？**
* **原因**：目标进程具有比本工具更高的特权级别（例如以管理员身份运行的终端）。请退出本软件，右键选择 **“以管理员身份运行”** 重新启动。
* **Q: 点击测试时窗口弹出来了，但是光标不在输入框内？**
* **处理方式**：请使用右上角的准星重新拖动至输入框中心松开，确保 `屏幕 X` 和 `屏幕 Y` 坐标不为 0。调度器会在唤醒窗口后模拟点击该物理坐标以对焦输入框。
* **Q: 触发时会干扰我当前的操作吗？**
* **说明**：因为工具采用系统原生事件模拟，执行瞬间会将目标窗口拉至前台、获取焦点并模拟键鼠；执行过程耗时约 0.3~0.5 秒，完成后即恢复后台等待状态。可选地，每次发送前会对鼠标/键盘锁定约 1 秒以避免冲突。
