# WindowsLoopSend 定时指令自动发送工具

一款专为 Windows 平台打造的轻量级无侵入式自动化交互工具。无需安装任何扩展或插件，通过底层 API 强行抢占窗口焦点，结合剪贴板注入与键盘/鼠标事件模拟，实现定时向指定窗口（OpenCode、VS Code、Windows Terminal、CMD、浏览器等）自动粘贴提示词并回车发送。

---

## 核心特性

* **准星拖拽瞄准（Spy++ 风格）**：按住准星图标直接拖曳至目标输入框松开，自动获取目标窗口句柄并记录全局屏幕物理坐标。
* **突破抢焦点拦截**：内置 `AttachThreadInput` 与键盘状态模拟机制，穿透 Windows 防后台偷焦点的限制，强制唤醒并置顶目标窗口。
* **高分屏 DPI 自适应**：原生调用 `SetProcessDpiAwareness`，避免 2K/4K 屏或 Windows 缩放比例（125%、150% 等）导致鼠标点击坐标错位。
* **剪贴板原子输入**：采用系统剪贴板配合 `Ctrl+V` 模拟粘贴，彻底解决逐字模拟按键带来的长文本丢字、特殊标点乱码及中文输入法拦截问题。
* **多策略调度引擎**：
* **单次模式**：指定日期与精确时间执行，任务完成后自动终止。
* **循环模式**：设置执行间隔（分钟），支持配置启动时是否立即执行首发。
* **有效周期保护**：支持配置任务开始与截止日期，超时自动忽略。

## 快速上手

### 1. 克隆仓库并安装依赖

```bash
git clone https://github.com/yezijinn/win-auto-sender.git
cd win-auto-sender
pip install -r requirements.txt

```

### 2. 运行程序

> **重要提示（UAC 权限隔离说明）**：
> 若目标窗口是以**管理员身份运行**的进程（如管理员权限的 Windows Terminal、VS Code 或 CMD），本工具**必须同样以管理员身份运行**，否则 Windows 系统的 UIPI（用户界面特权隔离）机制会静默拦截所有按键与鼠标消息。

以管理员身份打开终端并执行：

```bash
python win_auto_sender.py

```

## 使用步骤

1. **绑定窗口与定位编辑框**：
* **方法 A（推荐）**：鼠标左键按住界面右上方的 **准星方框** 不放，光标变为十字，拖拽到目标软件的文字输入区后松开。程序会自动绑定该窗口并在下方回填坐标。
* **方法 B**：在下拉列表中直接选择已打开的可见窗口，手动调整或清空坐标。


2. **输入提示词**：在文本框中写入准备发送的 Prompt、命令或代码。
3. **设置触发策略**：
* **单次任务**：设置具体的触发时间（若设定时间已过期，启动时会提示是否顺延至次日）。
* **循环任务**：勾选循环任务，设定循环间隔分钟数，并选择是否立即执行第 1 次。
* **日期范围**：确认任务生效的开始日期和截止日期。


4. **测试与挂机**：
* 建议先点击 **“⚡ 立即测试触发 1 次”**，确认窗口能正常弹到前台并回车发送。
* 测试通过后，点击 **“▶ 启动定时监听”** 即可挂机运行。

## 常见问题与排查 (FAQ)

* **Q: 为什么日志显示“已发送”，但目标窗口完全没有输入内容？**
* **原因**：目标进程具有比本工具更高的特权级别（例如以管理员身份运行的终端）。请退出本软件，右键选择 **“以管理员身份运行”** 重新启动。


* **Q: 点击测试时窗口弹出来了，但是光标不在输入框内？**
* **处理方式**：请使用右上角的准星重新拖动至输入框中心松开，确保 `屏幕 X` 和 `屏幕 Y` 坐标不为 0。调度器会在唤醒窗口后模拟点击该物理坐标以对焦输入框。


* **Q: 触发时会干扰我当前的操作吗？**
* **说明**：因为工具采用系统原生事件模拟，执行瞬间会将目标窗口拉至前台、获取焦点并模拟键鼠。执行过程耗时约 0.3~0.5 秒，完成后即恢复后台等待状态。
